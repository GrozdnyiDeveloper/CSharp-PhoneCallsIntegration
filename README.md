# Интеграция CRM с базой данных речевой аналитики
В данном репозитории представлена интеграция CRM с базой данных речевой аналитики. Данная интеграция создаёт в CRM новые записи Звонков при добавлении новых записей в БД речевой аналитики. 

Проект crmPark.Integration.SpeechAnalysis представляет собой консольное приложение по переносу данных речевой аналитики из внешней БД в CRM. В проекте также находится файл transcriptions.sql, содержащий сам запрос к внешней БД.
