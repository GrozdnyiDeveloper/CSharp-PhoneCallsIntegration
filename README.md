# Интеграция CRM с базой данных речевой аналитики
В данном репозитории представлены примеры доработок интеграций CRM с различными телефониями (MigthyCall, Comagic и Megafon). Данная интеграция создаёт в CRM новые записи Звонков при добавлении новых записей в БД речевой аналитики. 

Проект crmPark.Integration.SpeechAnalysis представляет собой консольное приложение по переносу данных речевой аналитики из внешней БД в CRM. В проекте также находится файл transcriptions.sql, содержащий сам запрос к внешней БД. 

**Архив имеет следующее содержимое:**
- crmPark.Integration.SpeechAnalysis - Проект, представляет собой консольное приложение по переносу данных речевой аналитики из внешней БД в CRM (запрос к внешне БД содержиться в файле transcriptions.sql)
- crmPark.Blacklist.Statistics - Проект, содержащий консольное приложение по обновлению статистических данных в записях Номеров телефонов в системе Dynamics 365. Предполагается, что в рамках интеграции для приложения настроен автоматический запуск раз в 15 минут
- crmPark.Integration.External - Проект, содержащий API приложение (располагающееся на сервере телефонии) для взаимодействия телефонии MightyCall с CRM
