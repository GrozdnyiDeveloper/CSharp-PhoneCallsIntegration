# Интеграция CRM с внешними телефониями Comagic и MightyCall
В данном репозитории представлены примеры доработок интеграций CRM с различными телефониями (MigthyCall, Comagic и Megafon). 

## Comagic.Integration - Содержит проекты интеграции CRM с телефонией Comagic
- Integration.SpeechAnalysis - Проект, представляет собой консольное приложение для переноса данных речевой аналитики из внешней БД в CRM (запрос к внешне БД содержиться в файле transcriptions.sql)

## MightyCall.Integration - Содержит проекты интеграции CRM с телефонией MightyCall
- Blacklist.Statistics - Проект, содержащий консольное приложение по обновлению статистических данных в записях Номеров телефонов в системе Dynamics 365 
- Integration.BlackList - Проект, содержащий API приложение (располагающееся на сервере телефонии) для взаимодействия телефонии MightyCall с CRM
- Integration.LinkMegafonToMightyCall - Проект, представляет собой консольное приложение производящее сопоставление новых перенесённых из телефоний Megafon и MightyCall записей Звонков в CRM по их Сессиям
